# Tailwind Gradients

A Tailwindv4/SVG gradient generator that creates radial/oval CSS gradients for Tailwind CSS and SVG formats. Real-time preview, layer-based editing, blend modes, and advanced features like blur filters.


## Installation

```bash
# Clone the repository
git clone https://github.com/xcrap/tailwind-gradient-generator.git

# Navigate to project directory
cd tailwind-gradient-generator

# Install dependencies
npm install
```

## Run

```bash
# Start development server
npm run dev
```

The application will be available at `http://localhost:3000`
